Let $(W,S)$ be a Coxeter system with $|S|=k$ and $\mathbb{N}:=\Set{0,1,2,\ldots}$ the set of natural numbers. We consider on $W$ the Bruhat order and on the Cartesian product $\mathbb{N}^k$ the componentwise order. A function $L: W \rightarrow \mathbb{N}^k$ is a Lehmer code if:
    \begin{enumerate}
        \item it is rank-preserving and injective;
        \item the image $\mathrm{Im}(L)$ is a a multicomplex, i.e. an order ideal of $\mathbb{N}^k$;
        \item the function $L^{-1}: \mathrm{Im}(L) \rightarrow W$ is order-preserving. 
    \end{enumerate}
The list provides a Lehmer code $L$ for type $E_6$ such that the multicomplex $\mathrm{Im}(L)$ has $71$ maxima. It is known that type $E_6$ does not
admits a Lehmer code such that $\mathrm{Im}(L)$ has a unique maximum.
